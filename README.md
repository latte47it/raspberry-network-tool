# Raspberry Network Tool

Tool Bash per Raspberry Pi/Linux per:

- informazioni hardware
- sistema operativo
- RAM e disco
- programmi installati
- servizi attivi
- informazioni di rete
- scansione dispositivi LAN
- scansione porte
- identificazione servizi
- scansione di singoli IP
- generazione report

## Requisiti

- Linux / Raspberry Pi OS
- Bash
- nmap
- systemd

## Installazione

```bash
sudo apt update
sudo apt install git nmap
